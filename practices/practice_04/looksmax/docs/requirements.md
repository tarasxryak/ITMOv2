# Looksmax Grocery: контракт

Браузерная игра: 10 раундов, в каждом три продукта ВкусВилла. Игрок выбирает тот, что «пизже по КБЖУ». В конце — процент попаданий, ранг и корзина ВкусВилла из выбранных продуктов.

## 1. КБЖУ

Источник — поле `properties[]` товара ВкусВилла с именем «Пищевая и энергетическая ценность в 100 г». Значение — строка, иногда с несколькими производителями через `<br>`:

```
ООО "ЛЕБЕДЯНЬМОЛОКО": белки 16 г, жиры 5 г, углеводы 3 г; 121 ккал<br>ООО "КУРСКОЕ МОЛОКО": ...
```

- Берётся первый блок до `<br>`.
- Из него извлекаются белки, жиры, углеводы (г) и энергия (ккал). Десятичный разделитель — точка или запятая.
- Обязательны белки и ккал. Если их нет или ккал ≤ 0, КБЖУ считается отсутствующим.
- Жиры и углеводы могут быть не указаны (у мяса и рыбы ВкусВилл пишет «белки 16 г, жиры 14 г, ; 190 ккал»). Отсутствующее значение считается 0.

## 2. Looksmax-скор

```
score = белки × 4 / ккал
```

Доля калорий из белка, от 0 до 1. Округление до 3 знаков. Больше — лучше.

## 3. Раунд

- Три разных товара из одного поискового запроса (одной категории).
- У всех трёх есть КБЖУ.
- Победитель один: его скор выше второго места минимум на 0.03.
- Порядок товаров в раунде не выдаёт победителя.

## 4. Валюта: лукс-коины

- Старт: 0.
- Верный выбор: +10.
- Серия: начиная с третьего верного ответа подряд, ещё +5 за каждый.
- Подсказка «мьюинг» стоит 15 и убирает один неверный вариант текущего раунда. Недоступна, если коинов меньше 15. Баланс не уходит в минус.

## 5. Ранг

Процент = верные / 10 × 100.

| Процент | Ранг |
|---|---|
| 0–19 | sub3 |
| 20–39 | sub5 |
| 40–49 | LTN |
| 50–59 | MTN |
| 60–69 | HTN |
| 70–79 | chadlite |
| 80–99 | chad |
| 100 | true adam |

## 6. Корзина

После 10 раундов выбранные игроком товары (по 1 шт.) отправляются в `vkusvill_cart_link_create`, игрок получает ссылку на корзину. Ошибка ВкусВилла не ломает экран результата: показывается понятное сообщение.

Браузер не может вызвать ВкусВилл напрямую: сервер требует `Content-Type: application/json`, а на CORS-preflight (`OPTIONS`) отвечает 401. Поэтому игру раздаёт локальный `serve.py` (только stdlib), он же принимает `POST /api/cart` с телом `{"xml_ids": [..]}` и вызывает `VkusVillClient.cart_link`. Ответ: `{"link": "..."}` или `{"error": "текст"}` с кодом 4xx/5xx.

## 7. Свой MCP-сервер `looksmax`

| Tool | Вход | Выход | Ошибочный вход |
|---|---|---|---|
| `score_product` | `product_id: int` | id, название, КБЖУ, скор | id ≤ 0; товар не найден; у товара нет КБЖУ |
| `build_round` | `query: str` | запрос, 3 товара с КБЖУ и скором, `winner_id` | пустой запрос; меньше 3 подходящих товаров или нет единственного победителя |
| `judge_round` | `product_ids: list[int]`, `choice_id: int` | верно ли, `winner_id`, скоры | не ровно 3 id; повторы; `choice_id` не из списка |

Ошибки возвращаются как ошибка tool с текстом, который объясняет, что исправить.
