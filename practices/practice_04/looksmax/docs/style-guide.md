# Style guide

1. Проверяй поведение через публичные функции `core/` и tools сервера, а не через внутренности.
2. Только стандартная библиотека Python и `mcp` из `requirements.txt`. Без новых фреймворков ради маленькой правки.
3. Сеть изолирована в `core/vkusvill.py`: остальной код получает уже разобранные данные, транспорт подменяется в тестах.
4. Ошибки входа — `ValueError` с текстом по-русски, который говорит, что исправить. Сервер превращает их в ошибку tool.
5. Фронтенд без сборщиков и npm: чистые HTML, CSS и JS, данные раундов из `web/rounds.js`.

Пример:

```python
def score(kbju: Kbju) -> float:
    if kbju.kcal <= 0:
        raise ValueError("ккал должны быть больше нуля")
    return round(kbju.protein * 4 / kbju.kcal, 3)
```
