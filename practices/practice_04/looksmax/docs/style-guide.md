# Style guide

1. Проверяй поведение через публичные функции `core/` и tools сервера, а не через внутренности.
2. Python: только стандартная библиотека и `mcp` из `requirements.txt`. Без новых фреймворков ради маленькой правки.
3. Сеть изолирована в `core/vkusvill.py`: остальной код получает уже разобранные данные, транспорт подменяется в тестах.
4. Ошибки входа — `ValueError` с текстом по-русски, который говорит, что исправить. Сервер превращает их в ошибку tool.
5. Фронтенд — Vite, React, TypeScript, Tailwind и shadcn/ui в `web/`. Игровые правила — чистые функции в `web/src/lib/` с тестами vitest; компоненты только рисуют состояние.
6. Компоненты shadcn не пишутся руками: берутся из MCP shadcn (`get_component`) или `tools/shadcn_fetch.py` и лежат в `web/src/components/ui/` без правок. Своё оформление — классами в местах использования и токенами в `web/src/index.css`.
7. Тексты интерфейса — по-русски, обычным регистром, без капслока и без стрелок в кнопках. Кнопка называет действие: «Дальше», «Сдать корзину».

Пример (Python):

```python
def score(kbju: Kbju) -> float:
    if kbju.kcal <= 0:
        raise ValueError("ккал должны быть больше нуля")
    return round(kbju.protein * 4 / kbju.kcal, 3)
```
