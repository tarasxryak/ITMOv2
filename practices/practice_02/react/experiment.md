# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель: проверить, что каждая метрика с ID правила в practices/practice_01/problem.md связана с существующим правилом кейса и хотя бы одним существующим ID теста
- Доступные входы: practices/practice_01/problem.md, CASE.md, adr.md, tests_unit.md, tests_integration.md, tests_load.md, tests_e2e.md
- Разрешённые действия: чтение файлов, grep по practices/practice_01, запуск make step1
- Запрещённые действия: правка файлов Практики 1, обращение к сети, любые действия в GitHub
- Максимальное число шагов: 5
- Условие остановки и вопроса человеку: найдена ссылка на несуществующий ID теста или правило, либо метрика без связи с правилом — остановиться и спросить

## Запрос
Проверить связи метрик с правилами и тестами по Практике 1. Разрешены чтение/grep/make step1. Остановиться, если найдена несущ. ссылка или отсутствие связи. Максимум 5 шагов.
